# BREW SPOT Cafe E-Commerce Application

Welcome to the full-stack, production-ready Brew Spot application. This project has been transformed from a static UI mockup into a fully functional e-commerce platform using Next.js, Prisma, NextAuth, Zustand, and Tailwind CSS.

## Features Included
- **Authentication**: NextAuth credentials setup for customers and admins.
- **Dynamic Database**: Prisma ORM with SQLite (easily swappable to PostgreSQL).
- **Shopping Cart**: Client-side Zustand store with localStorage persistence.
- **Checkout Flow**: 4-step secure checkout with address management.
- **Admin Dashboard**: Protected routes for managing orders and stats.
- **Dynamic Catalog**: Full product browsing with category filtering and dynamic pricing for options (Size, Extra Shot, etc.).

## 1. How to run the application

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 2. Environment Variables

Create a `.env` file in the root directory (if not already present):

```env
DATABASE_URL="file:./dev.db"
NEXTAUTH_SECRET="brewspot-secret-key-for-development"
NEXTAUTH_URL="http://localhost:3000"
RAZORPAY_KEY_ID="rzp_test_replace_me"
RAZORPAY_KEY_SECRET="rzp_test_secret_replace_me"
```
*Note: Generate a strong `NEXTAUTH_SECRET` for production using `openssl rand -base64 32`.*

## 3. Database Setup (Prisma)

The application uses SQLite for zero-config local development. 
To initialize the database and seed it with 33 realistic cafe products:

```bash
npx prisma db push
npx prisma db seed
```

To view your database tables visually, you can run:
```bash
npx prisma studio
```

## 4. Admin Login Setup

The `npx prisma db seed` command automatically creates a default administrator account.

- **Admin Login Page**: `http://localhost:3000/login`
- **Email**: `admin@brewspot.com`
- **Password**: `admin123`

Once logged in, navigate to `http://localhost:3000/admin` to access the dashboard and manage orders.

## 5. Payment Gateway Setup (Razorpay)

Currently, the application implements a Mock structural flow for Razorpay in test mode during checkout.
To implement real payments:
1. Create a Razorpay account and get your Test/Live API keys.
2. Update `RAZORPAY_KEY_ID` and `RAZORPAY_KEY_SECRET` in `.env`.
3. In `src/app/checkout/page.tsx`, inject the Razorpay SDK script and pass the `orderId` generated by the backend API into the Razorpay options object.

## 6. How to add products

You can add new products in two ways:
1. **Admin Panel**: (Feature structure prepared) You can build out the `src/app/admin/products` page to insert products dynamically.
2. **Prisma Studio**: Run `npx prisma studio`, open the `Product` table, and click "Add Record". Make sure to link it to a valid `Category` ID.

## 7. How to deploy the application

1. **Database Migration**: If deploying to Vercel, SQLite cannot be used (as Vercel has an ephemeral filesystem). You must create a PostgreSQL database (e.g., using Neon, Supabase, or Render).
   - Change `provider = "sqlite"` to `provider = "postgresql"` in `prisma/schema.prisma`.
   - Update `DATABASE_URL` in your production environment variables.
2. **Push Code**: Push your code to a GitHub repository.
3. **Vercel**: Import the repository in Vercel.
4. **Environment Variables**: Add all variables from your `.env` to the Vercel project settings.
5. **Build Command**: Vercel automatically detects Next.js. Ensure your build command includes `prisma generate` (e.g., `npx prisma generate && next build`).
